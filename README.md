# Secure Laravel 13 API with Sanctum Authentication

A RESTful API built with **Laravel 13**, **Laravel Sanctum**, and **MAMP (MySQL)**. This repository contains the complete implementation and Postman verification for user registration, login, protected profile retrieval, and token revocation (logout).

---

## 🛠️ Tech Stack & Requirements

* **Framework:** Laravel 13
* **Authentication:** Laravel Sanctum (Bearer Tokens)
* **Database Management:** MAMP (MySQL)
* **API Testing Tool:** Postman
